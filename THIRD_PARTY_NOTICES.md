# Third-party notices

Статус документа: инвентаризация фактически обнаруженных зависимостей и материалов
для текущего состояния проекта. Проверено 27.11.2026. Этот файл не принимает
решение о лицензии самого репозитория: варианты приведены в конце отдельно.

## Источник проверки и границы

- Прямые зависимости взяты из `package.json`; установленные версии подтверждены
  командой `npm ls --depth=0`; точные версии и поля `license` сверены с
  `package-lock.json` (lockfileVersion 3).
- `npm ls` показывает дерево и версии, но в данном выводе не показывает лицензии;
  поэтому лицензия ниже — это поле из lockfile, а не предположение по названию
  пакета.
- В lockfile найдено 79 package entries: 73 MIT, 2 BSD-3-Clause, 2 ISC и 2 без
  поля `license`. Два последних остаются пробелом, пока их собственные LICENSE/
  package metadata не проверены отдельно.
- `docs/sauat/SOURCES.md` содержит кандидатов и референсы. Они не включены ниже
  как использованные зависимости, если их нет в текущем `package.json`/
  `package-lock.json`.

### Что разрешено и что нельзя предполагать для npm

- Для пакетов с MIT/BSD-3-Clause/ISC обычно разрешены использование, изменение и
  распространение при сохранении требуемых copyright/license notices; для
  BSD-3-Clause нельзя создавать впечатление одобрения проекта авторами. Точный
  текст лицензии каждого пакета и наличие обязательных notice-файлов в
  распространяемом архиве не проверены.
- Пока `busboy` и `streamsearch` не проверены по upstream metadata/LICENSE,
  нельзя утверждать, что их лицензии совместимы с выбранным способом
  распространения. Это открытый блок, а не разрешение на свободное копирование.
- `Lucide` (ISC), `vite-plugin-pwa`, `Dexie` и другие строки из `SOURCES.md` —
  кандидаты/референсы, не текущие runtime-зависимости; нельзя указывать их как
  использованные библиотеки без отдельного подтверждения.

## Шрифты

В `public/`, `src/`, `content/` и `docs/slides/` файлов `woff`, `woff2`, `ttf`,
`otf` и `eot` не найдено. CSS перечисляет `Inter`, `ui-sans-serif`, `system-ui`,
`-apple-system`, `BlinkMacSystemFont` и `Segoe UI` как имена font stack; шрифт
`Inter` не поставляется в репозитории как файл или npm-зависимость.

Следовательно, отдельного bundled-font notice сейчас нет. Какие шрифты реально
есть на устройстве пользователя, их системные условия и возможная отдельная
лицензия установленного `Inter` не проверены — **пробел**.

## Что не является разрешением

- Наличие файла в рабочем дереве не доказывает право на его распространение.
- Запись в `SOURCES.md`, поисковый референс или совет использовать библиотеку не
  равны импорту кода/ассета и не заменяют проверку конкретной версии.
- Текущий документ не разрешает копировать чужие истории, фотографии, датасеты,
  UI, бренды или материалы друга. Для них нужна отдельная проверка источника,
  лицензии, атрибуции и согласия; такая проверка здесь не выполнена.
- Не проверено наличие полного набора upstream LICENSE/NOTICE-файлов в итоговом
  архиве или публикации. Перед распространением нужно собрать notices минимум
  для всех фактически включённых npm-пакетов и закрыть два lockfile-пробела.

## Варианты лицензии самого репозитория — решение не принято

Этот notice не объявляет лицензию `Saulat_Sauat`. Возможные модели, которые нужно
выбрать отдельно после проверки прав:

1. Лицензия кода (например, MIT или Apache-2.0) отдельно от контента/ассетов;
   для контента назначить только те условия, на которые у команды есть права.
2. Раздельная лицензия: код — permissive license, оригинальные истории и
   иллюстрации — отдельные условия или CC-лицензия с явной атрибуцией.
3. Пока права не сведены, оставить репозиторий без публичного grant/`LICENSE` и
   распространять только по отдельному разрешению; это не отменяет лицензии
   npm-зависимостей и обязательные notices.

Ни один из вариантов выше не выбран.
