# План пилота в одной сельской школе

Это план проверки, а не отчёт о проведённом пилоте. Пользователи, школа и результаты заранее не заявляются.

## Подготовка

1. Выбрать один 7–9 класс и получить согласие школы.
2. Запустить на одном ноутбуке без интернета; отдельно проверить сценарий с Ollama.
3. Выбрать 12–20 заданий: чтение, математика в жизни, русский и казахский. Учитель добавляет один короткий текст TXT/PDF.
4. Не собирать ФИО, почту, телефоны и биометрию. Для учеников использовать случайные псевдонимы.

## Метрика

Основная метрика: доля верных ответов по каждому навыку до/после.

`доля = верные ответы / все ответы × 100%`

Сравнить отдельно `find`, `infer`, `evaluate`, `math`, а также русский/казахский и задания 1–3 уровней сложности. Дополнительно записать долю завершённых заданий, число обращений к подсказкам и короткую анкету понятности. Не использовать рейтинг учеников.

## Процедура

Провести короткий входной набор без подсказок, 3–5 учебных сессий, затем эквивалентный выходной набор. Сохранить backup JSON и CSV; сравнивать только обезличенные псевдонимы. Учитель проверяет сложные вопросы и случаи «не могу подтвердить по тексту» вручную.

## Критерии решения

После пилота команда решает, какие задания переписать, где нужна казахская редактура, работает ли слабый ноутбук и хватает ли офлайн-режима. Порог улучшения заранее не объявляется: сначала нужен реальный базовый замер.
