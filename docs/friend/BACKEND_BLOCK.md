# Блок Олжаса (независимый, можно подключиться в любой момент)

Ты не блокируешь основную разработку. Твои задачи касаются только твоих папок: `ops/**`, `eval/persona/**`, `docs/friend/**` и твоих историй в `content/<id>.json`. Читать: `docs/sauat/CONTRACT.md`, `schema.json`, `SOURCES.md`, `CONTENT_GUIDE.md`. Свой Codex запускай с `AGENTS.md` из `docs/sauat/` и этим файлом. В ветке `feat/ops-eval-content`; в `main` и `dev` не пушь без согласования.

|---|---|---|
| O01 | Скрипт проверки персонализации ИИ: 8–12 профилей ошибок (`eval/persona/profiles.json`), сравнение выбора модели с базовым правилом, отчёт `eval/persona/REPORT.md` | таблица профиль / выбор модели / выбор правила / совпало; честный вывод, персонализирует ли модель |

| O03 | Нагрузочная проверка 30 одновременных запросов к `/api/mentor` и `/api/events`, отчёт | время ответа, ошибки, лимиты |
