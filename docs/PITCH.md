# Описание для формы

«Сауат» — офлайн-платформа функциональной грамотности для учеников 7–9 классов в школах со слабым интернетом. Ученик читает оригинальные короткие тексты, объявления и бытовые математические ситуации, отвечает на вопросы трёх типов: найти информацию, сделать вывод, оценить/интерпретировать. Подсказка работает в три шага и всегда показывает цитату из источника, но не выдаёт готовый ответ до попытки.

В продукте уже работают локальный банк из 60 заданий (30 чтение, 20 математика в жизни, 10 смешанных; 25 на казахском), адаптивный выбор по последним ответам, прогресс по навыкам, серия дней и значки без рейтинга. Учитель вставляет текст или загружает TXT/PDF с текстовым слоем, получает черновики, правит и публикует задания классу; панель показывает карту навыков и экспорт CSV. Администратор переносит JSON-backup на флешке. Русский и казахский интерфейс, PWA-кэш и Docker Compose включены. Ollama `qwen2.5:1.5b` подключается локально опционально; без неё работает честный режим «Без ИИ».

Проверка: `npm install`, `npm test`, `npm start`, затем http://localhost:3000. AI-eval — 20 пар «вопрос → источник» и запускается `npm run eval:ai`. Пилот в одной сельской школе и сравнение доли верных ответов по навыку до/после — следующий шаг; реальные пользователи и метрики пока не заявляются.
