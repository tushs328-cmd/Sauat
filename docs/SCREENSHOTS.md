# Скриншоты

Каждый кадр снят с живого сайта `https://tushs328-cmd.github.io/Sauat/` через Playwright в чистом профиле; размеры viewport — 390×844 для телефона и 1280×720 для рабочего стола.

- `docs/img/phone_01_first.png` — первый экран SAUAT с карточками историй; доказывает, что стартовый экран и доступная история читаемы на телефоне.
- `docs/img/phone_02_task.png` — задание на телефоне 390×844: вопрос, варианты ответа и фрагменты-доказательства; доказывает основной сценарий чтения и выбора доказательства.
- `docs/img/phone_03_feedback.png` — обратная связь «Ответ верный, но доказательство нужно уточнить» и кнопка «Показать подсказку»; доказывает раздельную проверку ответа и доказательства.
- `docs/img/phone_04_hint2.png` — подсказка уровня 2 на телефоне 390×844 с уточняющим вопросом; доказывает пошаговую подсказку по правилам.
- `docs/img/phone_05_summary.png` — итог истории с артефактом и блоком «Что повторить»; доказывает сохранение результата, найденных доказательств и следующего шага.
- `docs/img/phone_06_offline.png` — открытый экран при отключённой сети со статусом «Готово офлайн»; доказывает доступность базового экрана офлайн.
- `docs/img/phone_07_teacher.png` — кабинет учителя после импорта экспортированных событий с блоком «Типы ошибок»; симуляция, не реальные ученики; доказывает ручной импорт и диагностику ошибки доказательства.
- `docs/img/desktop_08_map.png` — карта пяти историй на рабочем столе 1280×720 в режиме `?jury=1`; доказывает демонстрационное открытие карточек для жюри.
- `docs/img/desktop_09_teacher.png` — кабинет учителя на рабочем столе 1280×720 без импортированных результатов; доказывает доступ к импорту и честное отображение пустого состояния.
- `docs/img/desktop_10_about.png` — «О проекте» с описанием локальной Ollama, правил публичной версии и ручного экспорта/импорта; доказывает честно указанные ограничения демо.
