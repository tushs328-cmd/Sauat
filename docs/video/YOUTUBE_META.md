# YouTube — поля загрузки

## Название

SAUAT — демо учебного тренажёра доказательного чтения

## Описание

SAUAT — демо учебного тренажёра, в котором ученик отвечает на вопрос по истории, отмечает фрагменты текста в подтверждение ответа и получает подсказку при ошибке. Показаны основной сценарий, работа после кэширования без интернета, обмен результатами с учителем и демонстрационный сценарий гибридного наставника.

Прототип: https://tushs328-cmd.github.io/Sauat/
Код: https://github.com/tushs328-cmd/Sauat

Демо — симуляция, а не результаты реальных учеников. Пилот не проводился. Казахский текст ждёт проверки носителем. Озвучка — синтез речи ElevenLabs.

ИИ-инструменты разработки: Codex, ChatGPT, Claude, OpenAI ImageGen.

## Теги

SAUAT, доказательное чтение, читательская грамотность, образование, обучение, образовательный прототип, PISA, казахский язык, офлайн-обучение, учебный тренажёр

## Настройки

- Язык видео: русский
- Категория: Образование
- Аудитория: не для детей
- Обоснование аудитории: «Не для детей» выбрано, потому что ролик описывает прототип для общего и педагогического контекста, а не контент, направленный на детей как на целевую аудиторию; окончательную отметку автор проверяет по правилам YouTube.
- Доступ: **Доступ по ссылке** (Unlisted), не «Закрытый».

## Что нажать в YouTube Studio

1. Откройте `studio.youtube.com` и войдите в аккаунт.
2. В меню слева нажмите **Создать → Загрузить видео**.
3. Выберите файл `docs/video/SAUAT_pitch.mp4`.
4. На шаге **Сведения** вставьте название и описание из этого файла, добавьте теги и выберите язык видео **русский**.
5. В поле **Аудитория** выберите **Нет, это видео не для детей**, затем в дополнительных настройках выберите категорию **Образование**.
6. На шаге **Субтитры** добавьте `docs/video/SAUAT_pitch.ru.srt` как русские субтитры.
7. На шаге **Видимость** выберите **Доступ по ссылке**, проверьте, что не выбран режим **Закрытый**, и нажмите **Сохранить**.
8. Скопируйте ссылку на видео и откройте её в окне инкогнито без входа в аккаунт; проверьте, что видео запускается и русские субтитры включаются.

Правило доступа: видео «Доступ по ссылке» может смотреть любой, у кого есть ссылка, без входа в Google-аккаунт. Справка YouTube: [настройки доступа](https://support.google.com/youtube/answer/157177) и [выбор аудитории](https://support.google.com/youtube/answer/9527654).
