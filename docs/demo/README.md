# SAUAT demo

Все записи и события здесь — **СИМУЛЯЦИЯ**: сценарий не представляет реальных учеников.

## Сценарий кадров

Актуальный список кадров для трёхминутной репетиции находится в [SHOT_LIST.md](SHOT_LIST.md). Он рассчитан на `build:demo`: 7 записей открыты сразу — 5 practice (`case_001`–`case_005`) и 2 диагностики (`diag_entry_001`, `diag_exit_001`).

Статус контента показываем честно: все семь записей в demo-манифесте имеют `reviewStatus: draft`; казахский текст требует проверки человеком. На карте видна плашка «Демо-режим: все истории открыты». `case_004` и `case_005` намеренно демонстрируются без внешней картинки — клиент показывает безопасную SVG-заглушку.

Русские субтитры добавляются как фиксированный overlay в браузере. Синтетический прогон не заменяет пилот и не создаёт выдуманные результаты учеников.

## Запуск

Из корня `Saulat_Sauat` соберите demo и поднимите dist-сервер:

```text
npm run build:demo
py -m http.server 3400 --directory dist
node docs/demo/run-a29.mjs
```

Сценарий создаёт `demo.webm` и `demo-run.json`, а `demo.mp4` получается MP4-конверсией через установленный ffmpeg. Путь — «входная диагностика → case_001 → итоги истории → кабинет учителя», viewport `1280×720`, без звука, не дольше трёх минут.

Для репетиции жюри используйте [JURY_WALKTHROUGH.md](JURY_WALKTHROUGH.md). Кабинет показывает только импортированные события; пустой кабинет не маскируется под реальный класс.

Видео не включается в Git, если размер превышает практический лимит репозитория; JSON-отчёт сохраняет факт запуска и ошибку, если она возникла.
