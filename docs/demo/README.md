# SAUAT demo

Все записи и события здесь — **СИМУЛЯЦИЯ**: сценарий не представляет реальных учеников.

## Сценарий кадров

Актуальный список кадров для трёхминутной репетиции находится в [SHOT_LIST.md](SHOT_LIST.md). Он рассчитан на `build:demo`: 4 истории-приключения (`case_001`–`case_004`) и 2 диагностики (`diag_entry_001`, `diag_exit_001`) открыты сразу.

Статус контента показываем честно: все шесть записей в demo-манифесте имеют `reviewStatus: draft`; казахский текст требует проверки человеком. На карте видна плашка «Демо-режим: все истории открыты». `case_004` намеренно демонстрируется без внешней картинки — клиент показывает безопасную SVG-заглушку.

Русские субтитры добавляются как фиксированный overlay в браузере. Синтетический прогон не заменяет пилот и не создаёт выдуманные результаты учеников.

## Запуск

Из корня `Saulat_Sauat` после запуска demo-сборки:

```text
node tools/demo/run.js
```

По умолчанию создаются:

- `docs/demo/demo.webm` — примерно 3 минуты;
- `docs/demo/demo.mp4` — MP4-конверсия через установленный ffmpeg;
- `docs/demo/demo-run.json` — параметры и exit-состояние запуска.

Перед записью проверьте `npm run build:demo` и откройте dist-сборку. Для репетиции жюри используйте [JURY_WALKTHROUGH.md](JURY_WALKTHROUGH.md). Кабинет показывает только импортированные события; пустой кабинет не маскируется под реальный класс.

Для короткой проверки сценария:

```text
$env:DEMO_DURATION_MS='30000'; node tools/demo/run.js
```

Видео не включается в Git, если размер превышает практический лимит репозитория; JSON-отчёт сохраняет факт запуска и ошибку, если она возникла.
