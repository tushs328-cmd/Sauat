# SAUAT demo

Все записи и события здесь — **СИМУЛЯЦИЯ**: сценарий не представляет реальных учеников.

## Сценарий

Восемь глав в viewport 1280×720 демонстрируют хук/карту, документы, ошибку доказательства, подсказку, исправленный ответ, offline-перезагрузку, попытку открыть новую историю, диагностику и кабинет учителя. Русские субтитры добавляются как фиксированный overlay в браузере.

Приложение запускается только из временной копии `qa/.tmp/app` с `INCLUDE_DRAFT=1` и портом `3400`. Запись не меняет `src/`, `public/` или рабочий каталог контента.

## Запуск

Из корня `Saulat_Sauat` после запуска приложения из `qa/.tmp/app`:

```text
node tools/demo/run.js
```

По умолчанию создаются:

- `docs/demo/demo.webm` — примерно 3 минуты;
- `docs/demo/demo.mp4` — MP4-конверсия через установленный ffmpeg;
- `docs/demo/demo-run.json` — параметры и exit-состояние запуска.

Сценарий не подменяет недоступные функции: на текущем состоянии новая история остаётся «Скоро откроется», а offline-перезагрузка воспроизводит BUG-001. Кабинет учителя показывается только если он присутствует в текущем приложении; выдуманные результаты не добавляются.

Для короткой проверки сценария:

```text
$env:DEMO_DURATION_MS='30000'; node tools/demo/run.js
```

Видео не включается в Git, если размер превышает практический лимит репозитория; JSON-отчёт сохраняет факт запуска и ошибку, если она возникла.
