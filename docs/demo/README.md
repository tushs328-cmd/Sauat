# SAUAT demo

Все записи и события здесь — **СИМУЛЯЦИЯ**: сценарий не представляет реальных учеников.

## Сценарий

Шесть глав демонстрируют карту маршрута, открытие истории «Золотой человек», задание с подсказкой, ответы ученика, экспорт результата и финальный кадр. Русские субтитры добавляются как фиксированный overlay в браузере.

Приложение запускается только из временной копии `qa/.tmp/app` с `INCLUDE_DRAFT=1` и портом `3400`. Запись не меняет `src/`, `public/` или рабочий каталог контента.

## Запуск

Из корня `Saulat_Sauat` после запуска приложения из `qa/.tmp/app`:

```text
node tools/demo/run.js
```

По умолчанию создаются:

- `docs/demo/sauat-demo.webm` — примерно 3 минуты;
- `docs/demo/demo-run.json` — параметры и exit-состояние запуска.

Для короткой проверки сценария:

```text
$env:DEMO_DURATION_MS='30000'; node tools/demo/run.js
```

Видео не включается в Git, если размер превышает практический лимит репозитория; JSON-отчёт сохраняет факт запуска и ошибку, если она возникла.
