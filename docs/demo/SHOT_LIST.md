## Правила записи

- Не показывать персональные данные: только синтетические события и локальный anonymous ID.
- Не говорить «пилот проведён» или «контент approved»: все семь записей сейчас `draft`.
- Не называть Ollama облачным ИИ: в публичной версии используется rules fallback.
- Этот A29-ролик показывает основной путь; offline reload проверяется отдельным QA-сценарием с реальной остановкой сервера.
