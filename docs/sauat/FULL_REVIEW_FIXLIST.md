# SAUAT — полный список правок

Дата: 26.11.2026. Приоритеты рассчитаны на текущий локальный прототип; не
меняют владельцев файлов и не требуют push.

## Для Codex A

1. Выложить свежий `dist` на согласованный публичный hosting и проверить URL без
   аккаунта, маршрут `?jury=1`, загрузку всех 7 draft-историй и offline reload.
2. Записать/экспортировать финальное видео до 3:00, проверить реальную
   длительность и доступность ссылки; не использовать локальный файл как
   замену публичному URL.
3. Сверить кадры demo со сценарием: ответ, неверное доказательство, подсказка,
   offline-состояние, diagnostic и кабинет учителя должны быть реально видны.
4. Сохранить заметную маркировку demo/draft и «казахский текст на проверке»;
   не показывать черновой контент как approved.
5. Повторить ручной mobile/desktop/focus/keyboard/offline QA на свежей сборке;
   зафиксировать BUG-001, если stopped-server reload снова не проходит.
6. Проверить размеры всех локальных файлов сдачи: не более 5 файлов и каждый
   не более 20 MB; не выбирать лишний WebM, если он не нужен форме.

## Для контента и владельца B

1. Провести человеческую проверку KK и RU по каждому из 7 JSON: язык,
   однозначность вариантов, достаточность `acceptedEvidenceSets`, возрастная
   уместность и соответствие источнику.
2. Сверить факт-чек по точным URL и месту в источнике; не переносить чужие
   PISA-цифры, даты пилота или показатели эффективности без независимой проверки.
3. Проверить пары входной/итоговой диагностики на сопоставимость сложности;
   сохранить отсутствие подсказок и не выдавать 3+3 задания за
   стандартизированный тест.
4. Отделять факт, вывод и гипотезу. Для отсутствия подтверждения писать
   «не подтверждается данным текстом», а не «исторически опровергнуто».
5. После рецензии обновить только согласованные JSON/Markdown, повторить
   `npm run validate`, тесты и сборку; до этого оставить `reviewStatus: draft`.
6. Подготовить согласованный план пилота: новые тексты, первая попытка без
   подсказок, показатель «верный ответ + достаточное доказательство», пропуски,
   язык и ограничения причинного вывода. Результатов пока нет.

## Для владельца сдачи

- Подставить и открыть публичные ссылки на прототип, код, видео и слайды.
- Проверить финальную форму в приватном окне без локальной Ollama.
- Добавить строку атрибуции из `FRIEND_ATTRIBUTION.md`.
- Не добавлять регистрацию, Gmail, персональные данные детей или чужой формат
  импорта в обход нашего контракта.
