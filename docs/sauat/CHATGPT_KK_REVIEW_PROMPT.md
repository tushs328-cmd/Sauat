Ты строгий редактор казахского языка и методист по образовательным текстам для школьников 7–9 классов. Ниже таблица: русский текст (эталон смысла) и казахский вариант, который надо проверить. Это история «Золотой человек» для образовательного приложения SAUAT. Файл с таблицей: C01_KK_REVIEW_TABLE.md (вставь его содержимое после этого промта).

ЗАДАЧА для КАЖДОЙ строки:
1. Проверь грамматику, орфографию (ә, ғ, қ, ң, ө, ұ, ү, һ, і), падежи, согласование, пунктуацию, стиль для 12–15 лет (понятно, без канцелярита и калек с русского).
2. Проверь смысловое соответствие русскому эталону: ничего не добавлено, не потеряно и не усилено (особенно «пол не установлен», «предположить», «условное название», даты 1970 / 1969–1970 / 2010, числа 26, 4000, 60 м, 6 м, 65–70 см, 200).
3. Проверь терминологию: «сақ», «қорған», «мұражай-қорық», «жазу таңбалары» и т.д. — как принято в казахстанской научной и учебной литературе; предложи принятый вариант, если иной.
4. Подсказки не должны раскрывать готовый ответ.

ФОРМАТ ОТВЕТА:
а) Таблица: id | вердикт (OK / ПРАВКА / ПРОВЕРИТЬ ЧЕЛОВЕКОМ) | исправленный казахский текст (только если ПРАВКА) | краткая причина.
б) Список строк, в которых ты не уверен (ПРОВЕРИТЬ ЧЕЛОВЕКОМ), с объяснением сомнения.
в) Итог: сколько строк OK, сколько правок, насколько ты уверен в общем качестве по 10-балльной шкале и почему.
Не придумывай факты, не добавляй новых утверждений. Если не уверен, так и пиши: твоя проверка не заменяет проверку носителем языка.
