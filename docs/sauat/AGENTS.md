## Приоритеты реализации
T01: React/Vite/TS при пустом проекте; схему контента утвердить до параллельной работы. Локальные ресурсы. Минимальные зависимости, lockfile.
T02: игровой движок: hook -> document -> find -> infer -> prove -> reveal. Типы find/evidence_select/inference_evidence; отдельные оценки answerCorrect/evidenceCorrect. Набор доказательств допустим, если точно соответствует одному из утверждённых наборов. Нет скрытого начисления XP; повтор не удваивает награду. Для тренировок разрешены повтор и подсказки, для диагностики — первая попытка без подсказок. Учебная метрика не XP.
T03: оригинальная карта и коллекция; unlock после завершения; свободный возврат к уже пройденному. Не блокировать обучение из-за ошибок/жизней.
T04: production service worker с precache всех approved stories, локальных изображений, шрифтов, маршрутов; IndexedDB для прогресса; индикатор «готово офлайн» только после проверки. Обновление билда не стирает прогресс. Первый визит требует загрузки; не обещать автономность без первоначальной установки.
T05: mentor adapter -> Ollama qwen2.5:1.5b через контролируемый backend. Только skill/error и allowlisted IDs, schema validation, timeout, fallback. Реальный лог вызова без данных детей. UI честно маркирует источник подсказки (ИИ/правила). Не открывать Ollama публично напрямую. API keys только сервер, не VITE_*.
T06: диагностические задания и импорт/экспорт анонимного JSON; дедупликация по event ID; отклонять невалидные файлы и опасные поля; показатели показывают числитель/знаменатель и «нет данных». Никаких фиктивных результатов.

## Тесты и отчёт
Используй доступные scripts: build, typecheck, unit tests; если отсутствуют, добавь минимальные в рамках задачи. Тесты: неверное доказательство не даёт полного балла, повтор не дублирует XP, отсутствие переводов отклоняется, невалидный AI -> fallback, импорт не дублирует события. Если среда не даёт запустить, прямо сообщи. Не ставь DONE сам без принятия Claude.
Отчёт: ID / файлы / команды и exit codes / PASS-FAIL / блокеры / commit SHA (если коммит разрешён) / следующий шаг. Не меняй чужую ветку. Не копируй готовое приложение конкурента, бренд или ассеты. Проверяй лицензии и фиксируй использование в THIRD_PARTY.md.
