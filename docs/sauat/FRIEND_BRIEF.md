# Другу — контент, методика, презентация

Проект: SAUAT — Оқы да дәлелде. Твоя задача — проверенный образовательный контент, я отвечаю за приложение. Согласуй с Claude JSON-формат до массовой генерации. Можно использовать ИИ для черновиков, но каждый факт, перевод и ответ проверяешь сам. Истории не являются проверкой знания дат: все доказательства в тексте.

P0: три истории (Золотой человек, Арал, Байконур), 4 задания на каждую. На обоих языках. Для каждой: хук, 1–2 коротких документа/текста, стабильные IDs фрагментов, поиск факта, вывод, выбор доказательства и проверка утверждения, три подсказки на задачу, объяснение, финальное открытие, источник с конкретным URL, дата обращения, автор/права изображения. Если гипотеза — назвать гипотезой, вымышленный документ маркировать. Проверить смысловое соответствие kk/ru, не просто автоперевод. Не публиковать draft.

Диагностика: 3 входных и 3 итоговых задания на новых жизненных текстах (расписание, объявление, таблица). Сопоставимые навыки и сложность; без подсказок. Это демонстрация метода, не стандартизированный тест.

Источники: см. SOURCES.md. Начни с одного полного case_001.json и согласуй с разработчиком. Остальные — отдельные файлы. Не меняй схему после согласования без миграции. Шаблон content-template.json не готовый контент.

Презентация: 10 слайдов максимум, видео до 3:00. См. MASTER_PLAN.md, раздел 10. Не обещай прирост грамотности. Цель 8-недельного пилота +10 п.п. только гипотеза; сравнение на новых текстах и по возможности контрольная группа. PISA: OECD 2025, 36% достигли уровня 2 по чтению. Ссылка в SOURCES.md. EEF поддерживает стратегии понимания текста, не доказывает эффективность SAUAT.

Сдача другу/разработчику: файлы JSON, таблица источников, подтверждение человеческой проверки обоих языков, черновик слайдов и сценария. Первую историю нужно передать как можно раньше; три качественные важнее шести сырых.
