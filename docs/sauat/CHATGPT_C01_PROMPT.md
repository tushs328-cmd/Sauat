Подготовь ЧЕРНОВИК истории C01 «Золотой человек» строго по контракту: схема `schema.json` и правила `CONTRACT.md`, `CONTENT_GUIDE.md` (оба в папке `docs/sauat`; если не видишь файлы, спроси их у меня, не придумывай формат).

ТРЕБОВАНИЯ
1. Источники: используй только открытые страницы (список из `SOURCES.md`: kazakhstan.travel про музей/курган Иссык, e-history.kz, UNESCO и т.п.). Открой каждую в браузере и работай по тексту страницы. В `sources` для каждой: `id`, `title`, точный `url`, `accessedAt` (сегодняшняя дата). Если факт нельзя подтвердить источником, не включай его.
2. Историческая достоверность: отдели находку (что обнаружили) от вывода/гипотезы (кем был человек). Гипотезу так и называй. Даты, числа и имена только из источников; если источники расходятся, покажи расхождение, а не выбирай молча.
3. Структура: хук-вопрос; 1–2 документа короткими сегментами `e1…eN` (одна мысль на сегмент, каждый со `sourceId`); 4 задания: `find`, `infer_evidence`, `claim_check` («Поймай ИИ на ошибке»: утверждение «от ИИ» со скрытой ошибкой, которую опровергают конкретные сегменты), и ещё одно на выбор; у каждого 3+ вариантов ответа, `correctOptionIds`, все допустимые `acceptedEvidenceSets`, 3 подсказки (куда смотреть → наводящий вопрос → разбор без готового ответа), объяснение; `reward` (раскрытие загадки + название карточки-артефакта). Задания решаются только по сегментам, без внешних знаний.
4. Языки: текст на русском и на казахском. Казахский пишешь сам литературным языком, а не дословным переводом; всё казахское ставишь в `reviewStatus.kk: "draft"` и перечисляешь в отдельном списке «ПРОВЕРИТЬ ЧЕЛОВЕКОМ (kk)». Русский тоже `draft`, пока я не подтвержу.
5. Изображение: предложи, что нарисовать как собственную SVG-реконструкцию (описание сцены, без выдуманных деталей); если хочешь реальное фото, дай ссылку, автора и лицензию, но не вставляй в историю без проверки прав.
6. Формат ответа: (а) готовый JSON файла `content/case_001.json` одним блоком кода, валидный по схеме; (б) таблица «утверждение → источник (URL) → точная фраза-опора со страницы»; (в) список сомнений и расхождений; (г) список казахских строк для проверки. Никаких выдуманных фактов, цифр и цитат; если не уверен, пиши «ПРОВЕРИТЬ».
