# Product & UX — игровой стиль

SAUAT — путешествие по Казахстану, вдохновение Duolingo Adventures, но свой бренд, собственные иллюстрации и персонаж. Аудитория 12–15 лет: не детсад, не школьный портал. Визуал тёплый, современный, с лёгкой атмосферой экспедиции; бирюзовый #168D83, песочный #F5F2E8, тёмный #203C38, золотой #D5A125. Цвет не единственный сигнал состояния, контраст проверять. Не копировать сову/логотип Duolingo.

## 6 экранов P0
1. Язык + короткий onboarding, выбор RU/KK, без регистрации.
2. Карта/главная: большое приключение с хуком, путь из трёх миссий, XP, открытая коллекция. Честный прогресс.
3. История: fullscreen mobile, иллюстрация с локальным файлом, короткий текст, документы с ID фрагментов, прогресс 1/4. Не давать длинную простыню.
4. Универсальный экран задания: кнопки/выделение фразы, сравнение ответа и доказательства, постепенная подсказка, переход к следующему шагу, без наказания за ошибку.
5. Раскрытие тайны + музей: объяснение, артефакт, XP один раз, источники. Музей можно реализовать как вкладку карты.
6. Учитель: импорт JSON, три навыка, выбор ученика по анонимному ID, количество попыток и подсказок, пустое состояние. Диагностика использует экран задания.

## Игровой цикл
Хук: «Кем был Золотой человек?» -> находка -> документы -> найди факт -> сделай вывод -> выбери улику -> проверь утверждение -> раскрытие и карточка открытия. Сценарий не должен проверять предварительное знание даты. Каждое задание решаемо из материалов. Исторические споры обозначать как гипотезы. UX награждает любопытство, а не зависимость: без платных жизней, навязчивых уведомлений и принудительной серии дней.

Механики P0: поиск фрагмента, вывод с доказательством, проверка утверждения с доказательством (один движок, разные представления). P1: сортировка событий/сопоставление нескольких источников только после стабильного релиза.

Анимации CSS: 150–250ms переходы, плавный прогресс, реакция талисмана, optional confetti с reduced-motion. Все assets локальные WebP/SVG; не скачивать случайные чужие изображения. Для реальных музейных изображений — права по каждому файлу, иначе оригинальная иллюстрация с маркировкой реконструкции. Не зависеть от CDN. Минимум 44px tap targets, текст удобно читается на 360px. Не делать 20 экранов.
