# B25 — бюджет веса статической сборки

Проверено 26.11.2026 после `npm run build:demo` командой `npm run size`.
Скрипт считает raw-сумму и сумму gzip по каждому файлу, а также стартовый набор:
`index.html`, runtime JS/CSS, manifest, content, иконки и ассеты историй. Лимит
стартового набора — **1.5 MB gzip** (1 500 000 B).

| Категория | Файлов | raw | gzip |
|---|---:|---:|---:|
| HTML | 2 | 5.1 KB | 2.2 KB |
| JS | 10 | 108.6 KB | 33.8 KB |
| CSS | 2 | 45.9 KB | 10.7 KB |
| content | 8 | 141.6 KB | 36.5 KB |
| icons | 2 | 622 B | 493 B |
| прочее | 5 | 17.3 KB | 6.4 KB |
| **Всего dist** | **29** | **319.2 KB** | **90.1 KB** |
| **Стартовый набор** | **25** | **262.2 KB** | **72.8 KB** |

Результат: **PASS**, стартовый набор `72.8 KB gzip < 1464.8 KB` по выводу
`npm run size`. Это оценка gzip-суммы файлов, а не замер конкретного CDN с его
заголовками и транспортными накладными расходами. Первый запуск всё равно требует
сети для загрузки и установки Service Worker; после этого precache позволяет
продолжить маршрут офлайн. В режиме экономии трафика SW не предзагружает все
истории, а добавляет в кэш выбранную историю при открытии.
