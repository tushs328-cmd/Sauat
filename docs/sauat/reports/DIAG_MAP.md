# DIAG_MAP — сопоставимость входной и итоговой диагностики

`diag_entry_001` и `diag_exit_001` измеряют одну и ту же последовательность из трёх навыков. Тексты, числа и контексты разные; тип задания и логика проверки сохранены.

| Навык | Входная диагностика | Итоговая диагностика | Логика |
|---|---|---|---|
| `find` | `t1`: найти время прибытия автобуса на «Таскөпір» по `e2` | `t1`: найти сумму расходов на проезд во вторник по `e1` | Найти одну точную деталь в тексте/таблице. |
| `infer` | `t2`: вывести правила подготовки к мастерской по `e5`–`e6` | `t2`: вывести правильный порядок работы по `e4`–`e6` | Связать 2–3 фрагмента и сделать вывод, не смешивая детали. |
| `evidence` | `t3`: проверить утверждение о прибытии обратного автобуса в 08:40 по `e3` | `t3`: проверить утверждение о сохранении результата в папку «тексеру» по `e6` | Сопоставить утверждение с прямым доказательством и выбрать вердикт. |

Проверка: порядок навыков в обоих файлах — `find → infer → evidence`; `reviewStatus` не изменялся.
