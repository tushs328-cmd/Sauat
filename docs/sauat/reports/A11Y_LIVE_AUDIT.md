# A11Y live audit — SAUAT

Дата: 2026-11-27<br>
URL: https://tushs328-cmd.github.io/Sauat/<br>
Инструмент: Playwright CLI, Chromium, live-сайт. Код не менялся.

## Объём и метод

Проверены следующие экраны и состояния: карта, светлая и тёмная тема, вступление в маршрут, 4 задания маршрута с feedback/result, карточка артефакта, вступление в диагностику, 3 диагностических задания с завершением, кабинет учителя, гайд учителя, «Об игре», «О проекте» и `?jury=1`.

- Клавиатура: последовательный `Tab` по интерактивным элементам каждого проверенного типа экрана; проверены порядок, достижимость и `:focus-visible`.
- Доступные имена: Playwright snapshot и DOM-проверка для `button`, `a`, `input`, `select`, `textarea`; пропущенных имён у проверенных интерактивных элементов не найдено.
- Контраст: вычислен по WCAG через относительную яркость sRGB: `L = 0.2126R + 0.7152G + 0.0722B`, `CR = (Lmax + 0.05) / (Lmin + 0.05)`. Для обычного текста применён порог 4.5:1.
- Touch targets: измерен `getBoundingClientRect()` в live DOM. Минимум — 44×44 CSS px.
- Масштаб 200%: проверен эквивалентный рефлоу при CSS viewport 465×917 px, то есть половине исходной ширины 929 px.
- Reduced motion: Playwright `emulateMedia({ reducedMotion: 'reduce' })`.

## Findings

### A11Y-001 — P1: primary CTA не проходит контраст в тёмной теме

**Наблюдение.** В тёмной теме текст основной кнопки остаётся `#FFFFFF`, фон — `#68D0BD`; вычисленный WCAG contrast ratio равен **1.85:1**. Это ниже 4.5:1 для обычного текста и ниже 3:1 даже для крупного текста.

**Шаги воспроизведения.**

1. Открыть https://tushs328-cmd.github.io/Sauat/.
2. Нажать переключатель темы с доступным именем «Тёмная тема».
3. На карте найти кнопку «Начать» или открыть маршрут и найти primary CTA.
4. Сравнить computed `color` и `background-color`: `rgb(255,255,255)` на `rgb(104,208,189)`.

**Влияние.** Текст основной кнопки может быть плохо читаем пользователями в тёмной теме.

### A11Y-002 — P2: header controls имеют высоту 40 px, а не 44 px

**Наблюдение.** На карте и на внутренних экранах измерены controls высотой 40 px: кнопка «Назад» — 44×40 px, переключатель темы — 44×40 px, переключатель языка — 55.6×40 px. Это нарушает заданный минимум touch target 44×44 px по высоте.

**Шаги воспроизведения.**

1. Открыть live-сайт.
2. Перейти на карту, маршрут, задание, результат, диагностику, кабинет, гайд, «Об игре» или «О проекте».
3. Измерить header controls через DevTools/Playwright `getBoundingClientRect()`.
4. Получить высоту `40` для «Назад»/темы/языка.

**Влияние.** На сенсорных устройствах эти controls имеют меньшую вертикальную область нажатия, чем 44 px.

### A11Y-003 — P2: фокус импорта JSON попадает на прозрачный 1×1 input

**Наблюдение.** В кабинете учителя file input достижим клавиатурой, но его rect — 1×1 px, `opacity: 0`; focus outline применяется к этому невидимому input. Видимая label «Импорт JSON-файлов» размером 384×48 px не получает outline.

**Шаги воспроизведения.**

1. Открыть live-сайт и перейти в «Кабинет учителя».
2. Нажимать `Tab` после кнопки «Как пользоваться», пока фокус не попадёт на «Импорт JSON-файлов».
3. Наблюдать активный элемент: `input[type=file]`, `rect = 1×1`, `opacity = 0`, `outline = 3px solid` на невидимом input.
4. Видимая label не получает собственного outline; визуального индикатора на области импорта нет.

**Влияние.** Пользователь клавиатуры может не понять, что фокус уже находится на импорте и что `Enter` откроет выбор файла.

## Проверенные положительные результаты

- Tab-порядок покрывает основные действия на карте, маршруте, заданиях, результатах, диагностике и информационных экранах; элементы не пропускались.
- На проверенных экранах все интерактивные элементы имели доступное имя; иконографические controls имели явные aria-label.
- При 200%-эквивалентной ширине горизонтального overflow не обнаружено.
- `prefers-reduced-motion: reduce` распознан live-страницей; transition/animation duration — 0.00001 s.

## Не проверено

- Реальный вывод аппаратного screen reader (NVDA/VoiceOver/TalkBack) — не проверено.
- Фактический browser UI zoom 200% через меню браузера — не проверено; проверен эквивалентный CSS viewport 465×917 px.
- Физическое нажатие на реальном сенсорном устройстве — не проверено; проверены DOM-размеры targets.
- Все hover/active/disabled-комбинации и все возможные фоновые изображения — не проверено; контрастная таблица покрывает ключевые пары обычного состояния.
- Safari, Firefox и мобильные браузеры — не проверено.
