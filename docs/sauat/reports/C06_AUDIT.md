# C06_AUDIT — сложность и полярность claim-check

Проверены четыре practice-истории: case_001–case_004. В каждой есть find, infer_evidence и claim_check; дополнительные задания не нарушают порядок усложнения.

| История | find | infer_evidence | claim_check | Полярность claim |
|---|---|---|---|---|
| case_001 | t1: найти один факт по одному сегменту | t2: связать e6 и e11; t4: сопоставить четыре фрагмента и разные датировки | t3: проверить две даты по e2 и e3 | false |
| case_002 | t1: найти причину по e2 | t2: связать три фрагмента в причинную цепочку; t3: сопоставить два результата | t4: проверить даты, объёмы и план по трём фрагментам | false |
| case_003 | t1: найти место по e1 | t2: выстроить три события; t4: сопоставить текущий статус и договор | t3: проверить конфликт дат по e4 и e5 | false |
| case_004 | t1: найти условие по e2 | t2: объединить e3, e5 и e7 | t3: проверить составное истинное утверждение по e2, e5 и e6 | true |

Итог: типы и навыки различаются по задаче (find → infer_evidence → claim_check), infer-задания требуют больше одного сегмента, claim-check требует отдельного сопоставления утверждения с evidence. Полярность claim не одинакова: три false и одно true; правильные варианты claim-check занимают позиции a, a, a, b, поэтому ответ не угадывается по постоянному «Да/Нет» или позиции.
