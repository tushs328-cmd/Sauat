# SAUAT — запуск команды

1. Распакуй содержимое в корень существующего проекта после разрешённого старта хакатона. Не заменяй существующие AGENTS.md/CLAUDE.md без сравнения: если они уже есть, добавь ссылку на docs/sauat/AGENTS.md и docs/sauat/CLAUDE.md.
2. Открой Claude в проекте, отправь текст из docs/sauat/CLAUDE.md (раздел «Старт»). Он проверит текущий репозиторий и согласует контракт с другом.
3. Открой Codex, отправь ему docs/sauat/AGENTS.md и текущую задачу из TASKS.md. Claude не должен запускать новые задачи, пока нет результата предыдущей зависимости.
4. Antigravity получает docs/sauat/ANTIGRAVITY.md и URL работающего билда. По умолчанию только проверяет, не переписывает чужой код.
5. Другу отдельно отправь FRIEND_BRIEF.md и content-template.json. После утверждения схемы он отдаёт файлы в согласованную папку content/.
6. Все участники читают MASTER_PLAN.md и DESIGN.md. Claude ведёт TASKS.md; статус DONE только с доказательством.

Пакет содержит документацию и пустой шаблон, не готовое приложение. Никакие агенты автоматически не запускаются. GitHub не менялся. До старта проверь правила использования готовых библиотек и предварительных планов.

Путь к файлам: docs/sauat/. Если имеющийся проект использует другой стек, сохраняй совместимый стек; не начинай всё с нуля.
