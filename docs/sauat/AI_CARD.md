# AI Card — SAUAT

Статус: честное описание текущего прототипа. Публичный `dist` работает без
удалённого ИИ.

## Где используется ИИ

- Локальная Ollama может выбрать следующий шаг по allowlist; в публичном `dist`
  запросов к Ollama нет и работает проверяемый наставник на правилах.
- Codex, ChatGPT и Claude использовались для черновиков, архитектурного ревью и QA.
- ИИ не выставляет оценку, не заменяет учителя и не получает персональные данные
  ученика. События для кабинета анонимны.

## Ограничения

- Все истории и переводы требуют человеческой проверки; текущие статусы — `draft`.
- Пилот с учениками не проводился, поэтому нет подтверждённых цифр эффективности.
- Rules-наставник проверяем детерминированно; Ollama остаётся локальным опциональным
  адаптером и не является доказательством образовательного эффекта.
