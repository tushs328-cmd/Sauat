## Ограничения формы

- Не более 5 файлов.
- Каждый файл — не более 20 000 000 байт.
- Крупные бинарные файлы не нужно заменять архивом кода: код лучше указывать
  ссылкой на репозиторий.
- Перед отправкой открыть каждый URL в приватном окне без аккаунта и локальной
  Ollama.
