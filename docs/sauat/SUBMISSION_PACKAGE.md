# Пакет сдачи SAUAT

Статус: локальный список перед отправкой. Фактические публичные URL ещё не
подтверждены; этот файл не выдаёт локальные артефакты за опубликованные.

Текущий demo-манифест содержит **7 историй: 5 practice и 2 diagnostic**. Все
семь записей собраны с сохранённым `reviewStatus: draft`; для показа используется
`?jury=1`. Это не заменяет человеческую проверку RU/KK.

## Файлы и размеры

Размеры указаны по текущей рабочей копии на 26.11.2026.

|---|---|---:|---|
| Презентация PDF | `docs/slides/export/slides.pdf` | 225 675 bytes (0,23 MB) | Готов локальный PDF; публичная ссылка не подтверждена |
| Видео-питч | `docs/demo/demo.mp4` | 1 750 793 bytes (1,75 MB) | Есть локальный MP4; публичная загрузка и финальная проверка ссылки не выполнены |
| Исходный код | ссылка на репозиторий Sauat | URL пока placeholder | Не готово до появления подтверждённой публичной ссылки |

Дополнительный `docs/demo/demo.webm` имеет размер 20 324 598 bytes (20,32 MB),
поэтому его не следует выбирать для формы с ограничением 20 MB на файл. Для
отправки предпочтителен MP4 из таблицы.

## Ограничения формы

- Не более 5 файлов.
- Каждый файл — не более 20 MB.
- Крупные бинарные файлы не нужно заменять архивом кода: код лучше указывать
  ссылкой на репозиторий.
- Перед отправкой открыть каждый URL в приватном окне без аккаунта и локальной
  Ollama.

## Что ещё не готово

1. **Публичная ссылка на прототип:** нужно выложить свежий `dist`, проверить
   `?jury=1`, offline reload и вставить URL в форму.
2. **Публичная ссылка или финальная загрузка видео:** локальный MP4 есть, но
   внешний адрес для жюри ещё не подтверждён. Перед публикацией проверить, что
   ролик укладывается в лимит формы.
3. **Проверка казахского человеком:** draft-переводы и замечания KK нельзя
   объявлять окончательно проверенными по результатам автоматического lint.
4. **Ссылка на код и слайды:** в `SUBMISSION_FORM.md` остаются placeholders до
   того, как владелец проверит реальные URL.
