# Приватность и потоки данных SAUAT

Проверено по исходному коду SAUAT. Это описание путей данных, а не обещание
полной анонимности или сроков хранения, которые код не задаёт.

## 1. Устройство ученика

- Основное хранилище — IndexedDB `saulat-client` (версия 2), stores `meta`,
  `progress`, `events`, `eventArchive`, `teacherEvents`
  (`public/js/storage.js:1-2,19-29`). В `localStorage` находятся ключи
  `saulat-progress-v1`, `saulat-lang`, `saulat-theme-v1`, `saulat-onboarded`,
  `saulat-events-v1`, `saulat-draft-v1` (`public/js/storage.js:3-8`).
  Прогресс включает XP, состояние заданий и историю попыток; черновик хранит
  текущий экран и выборы (`public/js/storage.js:11-16,101-118`). При недоступной
  IndexedDB прогресс и события откатываются в `localStorage`
  (`public/js/storage.js:60-73,140-145`).
- `anonId` — сохранённый в `meta` технический идентификатор: сначала
  `crypto.randomUUID()`, затем локальный fallback (`public/js/storage.js:130-137`).
  Событие создаётся как объект с полями `eventId`, `anonId`, временем, версией
  контента, `storyId`, `taskId`, `skill`, `mode`, номером попытки, двумя
  boolean-результатами, `errorType`, `hintsUsed`, `firstTry`, языком и
  `mentorSource` (`public/js/main.js:255-259`). Полный allowlist серверной схемы
  тот же и не содержит имени, email, класса или школы
  (`src/events.js:1,16-39`). Это отсутствие полей в telemetry-событии; другие
  серверные функции проекта могут иметь отдельные данные.

## 2. Что выходит наружу

- **Публичный статический `dist` на GitHub Pages.** Сборщик ставит
  `__SAULAT_STATIC__`, делает `flushEvents()` немедленным `sent: 0` и добавляет
  в импорт только локальные проверки; вызов `/api/mentor` оборачивается условием
  `!__SAULAT_STATIC__` (`scripts/build-static.mjs:194-224,255-267`). Контент и
  shell загружаются относительными статическими URL (`scripts/build-static.mjs:46-85`),
  а precache ограничен безопасными относительными файлами
  (`scripts/build-static.mjs:90-120`). Поэтому по этому коду в статической
  версии наружу не отправляются события или запросы к API/Ollama; остаются
  только загрузки файлов сайта с его origin. Фактические access-логи GitHub
  Pages/CDN **не проверены**.
- **Серверная/локальная версия.** `flushEvents()` POST-ит `/api/events` пачкой
  до 500 событий и удаляет из запроса `errorType` (`public/js/storage.js:198-211`).
  Сервер валидирует и дедуплицирует их, затем пишет в JSON-файл хранилища
  (`src/events.js:49-75; src/storage.js:7-14,28-40`). Для подсказки браузер
  POST-ит `/api/mentor` только с `storyId`, `taskId`, `skill`, `errorProfile` и
  `lang` (`public/js/main.js:261-266`).
- Service worker серверной версии при сбое оставляет `/api/events` отложенным
  с маркером `x-saulat-offline: 1`; обычные API GET он не кэширует
  (`public/sw.js:35-60`).

## 3. Локальная Ollama

`src/mentor.js` формирует prompt только из ID истории и задания, навыка, языка,
числового/логического `errorProfile` и разрешённых списков `hintIds`,
`nextTaskIds`, стратегий и уровня (`src/mentor.js:95-115`). В POST к Ollama
уходят эта строка, имя модели и JSON Schema (`src/mentor.js:117-128`). Тексты
ученика и документы в этот вызов не передаются по проверенному коду. Ответ
принимается только с `strategy`, `hintId`, `nextTaskId` из allowlist; иначе
используются rules (`src/mentor.js:5-15,70-75,130-137`). Логи и срок хранения
данных внутри Ollama **не проверены**.

## 4. Экспорт и импорт учителя

Экспорт браузера — JSON `{ exportedAt, events }`; серверный экспорт добавляет
`summary` и доступен авторизованному учителю (`public/js/main.js:268-272;
src/server.js:139-143`). Импорт принимает массив либо объект `{ events: [] }`
(`src/events.js:43-46`). Для события проверяются типы, обязательные поля,
безопасные ID, ISO-дата, допустимые skill/mode/lang/source и `errorType`
(`src/events.js:16-40`). В статической сборке лимиты — максимум 500 событий и
2 МиБ JSON (`scripts/build-static.mjs:214-218`); серверный teacher upload также
ограничен 2 МиБ и 500 событиями (`src/server.js:64-68,126-136`). Дубли не
записываются по `eventId`: локально — против БД и текущей пачки, на сервере —
против файла и текущей пачки (`public/js/storage.js:181-195;
src/events.js:49-75`).

## 5. Безопасность и ограничения

- API rate limit по IP: по умолчанию 300 запросов/минуту; для `/api/mentor` —
  отдельный лимит 30/минуту. Тело mentor — не более 2 КиБ, общий JSON — 256
  КиБ, URL-encoded — 32 КиБ (`src/server.js:41-52,64-84,106-110`).
- Ответы защищены `nosniff`, `DENY`, строгой Referrer/Permissions Policy и CSP;
  `X-Powered-By` выключен (`src/server.js:55-67`).
- В импортированных данных UI не вставляет сырые поля событий: `esc` заменяет
  `& < > " '` (`public/js/main.js:21`), а кабинет показывает только числа,
  локализованные подписи и экранированное сообщение импорта
  (`public/js/main.js:221-226`). Это снижает риск XSS через импорт; фактическая
  эксплуатация в браузере **не проверена**.
- Технический `anonId` не равен полной анонимности: он постоянен для данного
  хранилища и может быть сопоставлен по времени/контексту. `localStorage` и
  IndexedDB доступны тому, кто пользуется профилем браузера/устройством; шифрование
  в проверенном коде не найдено. Отдельно: клиент допускает `mode: jury`, а
  серверный валидатор — только `practice` и `diagnostic` (`public/js/storage.js:163;
  src/events.js:31`), поэтому jury-событие может быть отвергнуто telemetry API.

## 6. Данные, место, доступ и срок

| Данные | Где хранятся | Кто видит | Срок |
|---|---|---|---|
| Прогресс, язык, тема, onboarding, черновик | Браузер: IndexedDB/`localStorage` | Пользователь устройства; код приложения | До очистки/сброса; автоудаление не проверено |
| События ученика | `events` + постоянный `eventArchive`; в static — `localStorage` до 500 | Пользователь устройства; при sync — локальный сервер | Архив до `resetProgress`/очистки; срок серверного хранения не задан |
| Импортированные teacher events | IndexedDB `teacherEvents` | Пользователь устройства и UI кабинета | Автоудаление не проверено; `resetProgress` этот store не удаляет |
| `/api/events` | JSON-файл `SAULAT_DATA_FILE` | Процесс/оператор сервера; teacher API после auth | TTL/удаление **не проверены** |
| Профиль `/api/mentor` | Запрос сервер → локальная Ollama; persistence в проверенном пути нет | Сервер и локальная модель | Срок логов Ollama **не проверен** |
| Статические файлы | origin GitHub Pages и browser cache | Посетитель и хостинг | Срок CDN/access-логов **не проверен** |
