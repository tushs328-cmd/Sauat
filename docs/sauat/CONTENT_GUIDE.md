# CONTENT_GUIDE — как писать историю (для ChatGPT, владельца и Олжаса)

1. **Формат:** один файл `content/<id>.json` по `schema.json` и `CONTRACT.md`. Начинай с `reviewStatus: {kk:"draft", ru:"draft"}`. Пока человек не проверил язык, статус не повышаем.
2. **История 3–5 минут:** хук-вопрос → 1–2 документа короткими сегментами (`e1…eN`, по одной мысли) → 4 задания (`find`, `infer_evidence`, `claim_check`, ещё одно по выбору) → раскрытие загадки (`reward`) → источники.
3. **Решается по тексту.** Каждое задание можно решить только материалами истории; предварительное знание дат и имён не требуется.
4. **Факты:** каждое историческое утверждение = сегмент со `sourceId`. Источники из `SOURCES.md`; в `sources` указывай точный URL и дату обращения. Пересказывай своими словами, длинные цитаты не копируй. Гипотезу называй гипотезой; вымышленный документ маркируй `isFictional`.
5. **Задания:** минимум 3 варианта ответа; `correctOptionIds` и `acceptedEvidenceSets` (все допустимые наборы); `claim_check` — ИИ-утверждение со скрытой ошибкой, опровержимой сегментами. 3 подсказки: 1 куда смотреть, 2 наводящий вопрос, 3 разбор без готового ответа. Ошибка не наказывается.
6. **Диагностика (`kind: diagnostic`):** новые жизненные тексты (расписание, объявление, таблица, инструкция), без подсказок, сопоставимые входные и итоговые задания. Это демонстрация метода, не валидированный тест.
7. **Изображения:** только свои SVG (с пометкой реконструкции) или с проверенной лицензией; поле `image` обязательно содержит `credit` и `license`. ИИ-картинки не выдавать за исторические.
8. **Казахский:** не автоперевод. Нужен человек, который проверит язык и смысл. Пока нет проверки, статус `draft`, в интерфейсе «на проверке».
9. **Проверка:** `npm run validate` должен проходить без ошибок. Подозрительные места помечай в описании коммита, а не в тексте задания.
