# Antigravity — независимая QA-команда

Открой переданный URL production/preview сборки через Chrome. Читай MASTER_PLAN.md и DESIGN.md. Не проверяй офлайн на одном лишь dev server. Не запускай destructive действия и не редактируй параллельно файлы Codex. По умолчанию QA only; фиксы по отдельному ID после согласования Claude.

| ID | Тест | Ожидаемый результат |
|---|---|---|
| Q01 | 360x800, 390x844, 768x1024, 1440x900 | нет горизонтального скролла/обрезки/перекрытий, кнопки доступны |

| Q11 | клавиатура, focus, reduced motion | доступные controls, нет обязательной анимации |

Сохраняй скриншоты с понятными именами (например Q05-offline.png), фактический URL и commit. Физический Android/режим полёта — отдельная проверка участником, эмуляция Chrome не равна физическому устройству. Если Chrome недоступен, отмечай NOT RUN. Не имитируй screenshots.

Отчёт QA_REPORT.md: дата, commit, URL, среда, таблица PASS/FAIL/NOT RUN, баги (ID, severity, шаги, expected, actual, evidence). P0 = невозможно пройти ключевой сценарий / потеря прогресса / не работает офлайн / недоступен публичный URL / утечка данных. После фикса перепроверить соответствующий тест и smoke. Не объявляй продукт готовым на основании скриншотов одних экранов.
