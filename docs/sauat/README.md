# SAUAT — пакет B

SAUAT — локально проверяемый прототип для практики чтения: ученик читает
короткую историю, выбирает ответ и фрагмент-доказательство. В demo-пакете
**7 историй: 5 practice и 2 diagnostic**; все семь остаются `draft`, а
казахский текст не проверен человеком.

## Сборка и пакет

```bash
npm install
npm test
npm run validate
npm run build:demo
node scripts/static-smoke.mjs --include-draft
npm run size
npm run pack:site
```

`npm run pack:site` сначала собирает demo `dist/`, затем создаёт `dist.zip`
рядом с папкой. В архиве используются прямые `/`-слэши; скрипт отклоняет
архив или отдельный файл больше 20 000 000 байт.

Для показа всех историй используйте `?jury=1`. Без параметра истории идут по
обычной прогрессии: следующая practice открывается после предыдущей, а
итоговая диагностика — после практики. Jury-прогресс изолирован от основного
прогресса и событий.

## Честные границы

- публичный `dist` работает без сервера и Ollama; подсказки там основаны на
  правилах;
- прогресс и события живут на устройстве; экспорт — JSON для передачи учителю;
- импорт ограничен проверкой схемы, 500 событий и 2 MiB на файл;
- текущие истории и переводы требуют человеческой редакторской проверки;
- пилот с учениками не проводился, образовательный эффект не измерялся;
- публичный hosting URL, видео URL и ссылка на слайды пока не подтверждены.

Исходный код находится в приватном репозитории; доступ жюри ожидает разрешения
владельца.
