# AI Card

## Модель и режимы

- По умолчанию: без ИИ, встроенный банк и правила подсказок.
- Опционально: локальная Ollama, модель `qwen2.5:1.5b`, URL через `OLLAMA_URL`, имя через `OLLAMA_MODEL`.
- Внешние облачные API не используются. Тексты ученика не отправляются в интернет.

## Назначение

Модель может сформулировать подсказку 2–3 уровня. Она получает только вопрос, варианты, одну цитату и инструкцию не называть правильный вариант. Ответ проходит защитную проверку: если текст содержит правильный вариант или формулировку «правильный ответ», приложение использует офлайн-подсказку.

## Известные ограничения

Модель может ошибиться, говорить слишком общо, не распознать казахскую формулировку или не сослаться на нужное слово. Поэтому UI всегда показывает цитату, а оценка ответа выполняется правилом по индексу варианта. Для свободных ответов и семантической проверки в текущей версии нет безопасного общего оценщика.

## Оценка

`eval/cases.json` содержит 20 фиксированных пар «вопрос → источник». Команда `npm run eval:ai` считает кейс пройденным только если доступная модель вернула подсказку, содержащую опору на источник. На текущем запуске Ollama не была настроена: фактический результат — `mode: not-run`, `passed: 0`, `failed: 0`, 20 кейсов `not-run`. Это отсутствие замера, а не нулевая точность.
