# GitHub Scout для «Сауат»

Безопасный исследовательский парсер публичных GitHub-метаданных для проекта «Сауат» (Órleu Hack 2026, Кейс 3). Ищет open-source проекты, библиотеки и казахские датасеты через GitHub REST API, оценивает лицензии, офлайн-пригодность и риски, но **никогда не клонирует и не запускает чужой код**.

## Запуск одной командой

Из папки `Saulat_Sauat`:

```bash
node tools/github_scout/scout.js
```

Дополнительные параметры:

```bash
node tools/github_scout/scout.js --queries tools/github_scout/queries.json --per-query 5 --max-repos 40 --no-cache
```

## Авторизация и лимиты API

- Если задана переменная `GITHUB_TOKEN`, парсер передаёт её в заголовке `Authorization` только в памяти.
- Если `GITHUB_TOKEN` не задан, парсер проверяет `gh auth token` (если `gh` авторизован), либо работает через анонимный REST API.
- Токен **никогда** не печатается в консоль и не записывается в файлы.
- Парсер соблюдает паузы между запросами, отслеживает `x-ratelimit-remaining` / `x-ratelimit-reset`, кэширует ответы в `docs/scout/.github-cache.json` (без секретов) и при нехватке core-квоты использует публичные JSON/raw метаданные без клонирования.

## Настройка поисковых запросов

Все шаблоны запросов находятся в `tools/github_scout/queries.json` и разделены по категориям:
- LAN-квизы, kahoot-подобные комнаты, тренажёры чтения и PISA-assessment;
- адаптивное обучение (spaced repetition, Leitner, FSRS);
- локальный ИИ на Ollama, RAG с цитатами, генерация вопросов из текста;
- PWA offline-first, QR-код/mDNS в Node.js, Express + SQLite роли;
- казахские датасеты QA/текстов, казахская лемматизация/стемминг и офлайн speech/TTS.

Для устойчивой выдачи при лимите Search API конфиг также содержит несколько `seed_repositories` — точечных публичных кандидатов KazQAD/казахской речи/RAG. Они читаются теми же REST metadata/README/tree-путями, не клонируются и не запускаются.

## Выходные файлы

- `docs/scout/results.json` — полные машинные результаты (включая оценки 0–100 и причины исключения);
- `docs/scout/results.csv` — плоская таблица для просмотра в Excel/Sheets;
- `docs/GITHUB_SCOUT.md` — отчёт на русском: топ-15 проектов, топ-5 казахских датасетов, отсеянные (🔴 GPL/AGPL/LGPL и без лицензии), «чего не делать» и честный абзац для жюри;
- `docs/THIRD_PARTY.md` — инвентарь кандидатов со статусом `предложено`;
- `docs/scout/SCOUT_DONE.md` — отметка о проверке всех критериев.
