# Mentor persona evaluation

`profiles.json` содержит 10 профилей ошибок. Скрипт сравнивает структурированный ответ модели с детерминированным правилом и печатает таблицу `профиль / модель / правило / совпало`.

Запуск без скачивания модели:

```powershell
$env:INCLUDE_DRAFT = "1"
npm run eval:persona
```

Для live-замера нужны уже запущенные Ollama и модель; скрипт ничего не устанавливает и не загружает.
