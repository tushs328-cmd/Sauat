# BUG-004 — цепочка экспорт → кабинет учителя не доступна в UI

- Severity: P1
- Status: reproduced as an acceptance gap
- Scope: W1 diagnostics, RU 360×800 and KK 768×1024, synthetic browser simulation (`СИМУЛЯЦИЯ`)

## Steps

1. Open the map and inspect the teacher/results controls.
2. Open the entry diagnostic and complete its three tasks.
3. Use «Экспорт результатов» / «Нәтижелерді экспорттау».
4. Look for the teacher cabinet and an import control.

## Expected

The exported event file can be imported into the teacher cabinet and the resulting numbers can be compared with the expected values.

## Actual

Export is available and downloads `saulat-events.json` in both tested languages. No teacher cabinet or import control is present in the visible UI (`teacherImportAvailable=false` in both diagnostic records), so the required import-and-compare step cannot be executed.

## Evidence

- `qa/out/results.json`, `diagnostic-ru-360.export` and `diagnostic-kk-768.export`.
- The map screenshot shows export/results controls but no teacher cabinet: `qa/out/screens/map-ru-360.png`.
