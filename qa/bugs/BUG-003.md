# BUG-003 — две заявленные истории недоступны ученику

- Severity: P1
- Status: reproduced
- Scope: W1, RU 360×800, synthetic browser simulation (`СИМУЛЯЦИЯ`)

## Steps

1. Open the map after choosing Русский.
2. Inspect the three story cards.
3. Try to open Аральское море or Байконур.

## Expected

All stories present in the map can be opened and run through the learner scenario, or the map accurately advertises only the available stories.

## Actual

The map shows `Истории 3`, but cards 02 and 03 are «СКОРО ОТКРОЕТСЯ» and have no playable route. Only «Золотой человек» is open, so the W1 all-stories scenario cannot be completed.
