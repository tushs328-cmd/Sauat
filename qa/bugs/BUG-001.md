# BUG-001 — офлайн-перезагрузка теряет приложение и историю

- Severity: P1
- Status: reproduced
- Owner: B (`src/scripts`, service-worker/offline lifecycle)
- Scope: W1, synthetic browser simulation (`СИМУЛЯЦИЯ`)
- Environment: `qa/.tmp/night-2026-11-26-391ad30` from `git archive HEAD`, `INCLUDE_DRAFT=1`, port 3400, RU, 360×800

## Steps

1. Start the app from the clean archive copy, choose Русский, start the route, and wait for «Готово офлайн».
2. Stop the server with Ctrl+C while the page is open.
3. Reload the page with the server stopped.

## Expected

The cached app shell and the loaded story remain available so the learner can continue offline after a server stop.

## Actual

The reload completes without a Playwright timeout (`reloadError=null`), but the visible body contains only «Перейти к игре»; `hasApp=false`, `hasStory=false`. Direct evidence recorded `serverStopped=true` and `readyBeforeStop=true`.
