# BUG-001 — офлайн-перезагрузка теряет приложение и историю

- Severity: P1
- Status: reproduced
- Scope: W1, synthetic browser simulation (`СИМУЛЯЦИЯ`)
- Environment: copy under `qa/.tmp/app`, `INCLUDE_DRAFT=1`, port 3400, RU, 360×800

## Steps

1. Open the app, choose Русский, start the route, and wait for «Готово офлайн».
2. Call `context.setOffline(true)`.
3. Reload the page.

## Expected

The cached app shell and the loaded story remain available so the learner can continue offline.

## Actual

Reload returns HTTP navigation without a Playwright timeout, but the visible body contains only «Перейти к игре»; `hasApp=false`, `hasStory=false`. The browser console also reports `Failed to load resource: net::ERR_FAILED @ http://localhost:3400/favicon.ico` during the offline reload.

## Evidence

- `qa/out/results.json`, scenario `offline-ru-360`: `status=FAIL`, `reloadError=null`, body=`Перейти к игре`.
- Screenshot: `qa/out/screens/offline-ru-360.png`.
